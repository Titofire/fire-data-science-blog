# Fire Service Data Science Blog

A blog about using data science in the fire service: response times, risk
modeling, station coverage, staffing, and more.

## Status

Planning. See [notes/hosting-options.md](notes/hosting-options.md) for the
hosting decision (Quarto + GitHub Pages).

## Data policy

Only aggregated or de-identified data is committed to this repository. Raw
incident, address, or patient data stays out of Git.
